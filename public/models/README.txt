The 3D models on this site are generated PROCEDURALLY in code (components/three/models.js),
so no .glb / .gltf file is required and nothing is downloaded at run time.

If you later have a genuine 3D scan or model of a real project, put the .glb file here and load it
with useGLTF from @react-three/drei in a dedicated component. Keep each file under a few MB.
